Methodology

Data is collected from Steam's publicly accessible game metadata and stored in DuckDB. SQL is used for data exploration and quality checks, while Python is used for statistical analysis, modeling and visualization.

The current dataset contains 215 successfully enriched games. Results should therefore be interpreted as observations within this sample rather than as representative statistics for the entire Steam catalog.
